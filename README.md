# Arena 60

Jogo de arena 2D para navegador criado com TypeScript, Phaser e Vite. O objetivo é sobreviver por 60 segundos, desviando dos inimigos e coletando moedas.

## Executar localmente

```bash
npm install
npm run dev
```

## Testes

```bash
npm run test
npm run test:bdd
npm run test:e2e
npm run test:all
```

## Build

```bash
npm run build
```
